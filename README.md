# Engagement Probe public report

This repository hosts the public-facing report for the Engagement Probe research
project: can a language model's internal state, read after it sees a prompt but
before it writes a single token, predict how fully it will answer?

- [Read the report online](https://tsoxxes.github.io/engagement-probe-report/)
- [Download the PDF](https://tsoxxes.github.io/engagement-probe-report/engagement_probe_report.pdf)

The research repository — protocol, prompt sets, analysis code, and the released
Round 2 data — is at
[TSoxxes/engagement-probe](https://github.com/TSoxxes/engagement-probe).

This repository contains only the published report. It is generated from the
master copy in the research repository; do not edit the report here directly.
